# Glossário: as palavras do mundo farmacêutico em português simples

**Para quem:** o analista de negócios que conduz o estudo e **não é da área farmacêutica**. Cada palavra tem **o que é** em linguagem comum, **um exemplo** e **onde aparece** no estudo. Quando uma ficha usar uma palavra daqui sem explicar, vale voltar a esta página.

**Dica de leitura:** pense que a fábrica de medicamentos é como uma empresa que **precisa provar, com papel e registro, que fez tudo certo**. A maioria das palavras abaixo é um jeito de **provar** ou de **evitar** que algo saia errado.

## As siglas e as normas

| Palavra | O que é, em português simples | Onde aparece |
|---|---|---|
| **ANVISA** | A agência do governo que fiscaliza medicamentos. É quem dá a licença para fabricar e vender. | Todas as fichas |
| **BPF** (Boas Práticas de Fabricação) | O "manual de conduta" obrigatório da fábrica: como fabricar, guardar, analisar e registrar para que o remédio seja seguro. | Todas as fichas |
| **RDC 658/2022** | A norma da ANVISA que **escreve** as BPF. É a "lei" que o sistema precisa respeitar. | Documento "O que a norma diz" |
| **Guia 33/2020** | Outro documento da ANVISA: diz como **provar que um sistema de computador é confiável** (como o iLabs). | Documento "O que a norma diz" |
| **GAMP 5** | Um método internacional para validar sistemas de computador. O Guia 33 se baseia nele. | Plano de testes |
| **SaaS** | Sistema vendido como serviço na internet (você acessa, não instala). O iLabs é assim. | Decisões do projeto |

## Os módulos (as "áreas" do sistema)

| Sigla | Nome | O que cuida, em uma frase |
|---|---|---|
| **GQ** | Garantia da Qualidade | O "sistema de regras e provas": documentos, treinamento, desvios, mudanças, auditoria e registro do produto. **Não fabrica nem analisa.** |
| **CQ** | Controle da Qualidade | O **laboratório**: analisa amostras e diz se o material ou o remédio está bom ou ruim (o **laudo**). |
| **Produção** | Fabricação | Onde o remédio é **feito**, seguindo uma ordem de produção. |
| **Estoque** | Almoxarifado | Onde os materiais e os remédios **ficam guardados**, com endereço e lote. |
| **Principal** | Cadastros gerais | Pessoas, funções, áreas, fornecedores, equipamentos. É a base que os outros usam. |

**Diferença que confunde:** **GQ** cria e confere as regras; **CQ** faz as análises de laboratório. Nomes parecidos, trabalhos diferentes.

## O material e o lote

| Palavra | O que é | Exemplo |
|---|---|---|
| **Lote** | Um grupo de produto feito (ou recebido) **junto, de uma vez**, com um número único. É como o "número de série da fornada". | Lote L-045 de um xarope, com 1.000 frascos. |
| **Matéria-prima** | O ingrediente que entra no remédio. | O princípio ativo, o açúcar do xarope. |
| **Item** | Qualquer coisa que o sistema controla: ingrediente, embalagem ou remédio pronto. | |
| **Produto acabado** | O remédio **pronto**, embalado. | A caixa de comprimidos. |
| **Quarentena** | **Material parado**, "de castigo", até alguém provar que está bom. Não pode ser usado nem vendido. | Chegou um ingrediente: fica em quarentena até o laboratório liberar. |
| **Laudo** | O **resultado oficial** da análise do laboratório: aprovado ou reprovado. | "Laudo aprovado: pode usar." |
| **Reprovado** | Material que **não passou** na análise. Não pode ser usado. | |
| **Validade** | A data **depois da qual o produto não pode mais ser usado**. | |
| **Reteste (ou reanálise)** | Analisar **de novo** um material antes de a validade acabar, para ver se continua bom. | O ingrediente tem 2 anos; aos 18 meses, reanalisa. |
| **Amostra** | Uma **pequena parte** retirada do lote para analisar. | |
| **Amostra de retenção / referência** | Uma amostra **guardada de propósito**, para o caso de precisar analisar de novo no futuro (por exemplo, numa reclamação). | |
| **FEFO / "primeiro que vence, primeiro que sai"** | Usar **antes** o que vence mais cedo, para nada estragar no estoque. | Dois lotes: usa o que vence em março antes do que vence em junho. |
| **Inventário** | **Contar o estoque de verdade** e comparar com o que o sistema diz. | Sistema diz 100, contagem acha 98: tem divergência. |
| **Remessa** | **Enviar** material ou produto para fora da empresa. | |

## Quando algo dá errado ou muda

| Palavra | O que é | Exemplo |
|---|---|---|
| **Desvio** | Algo que **saiu do combinado** no processo. Precisa ser registrado e investigado. | A máquina ficou 5 graus acima do permitido. |
| **Causa raiz** | O **verdadeiro motivo** do problema (não só o sintoma). | A máquina esquentou porque o sensor estava sem calibrar. |
| **CAPA** | **Ação Corretiva e Preventiva**: o que fazer para **consertar** o problema e para **não voltar a acontecer**. | Calibrar o sensor (corrige) e criar uma rotina de calibração (previne). |
| **Eficácia** | **Provar que a solução funcionou**, depois de um tempo. | Passados 3 meses, o problema não voltou. |
| **Mudança (controle de mudanças)** | Alterar **qualquer coisa** no processo, no produto ou no equipamento **só depois de avaliar o risco e aprovar**. | Trocar o fornecedor de um ingrediente. |
| **Autoinspeção / auditoria** | A empresa **vistoria a si mesma** (ou é vistoriada) contra a lista de regras. | Uma checklist de 80 perguntas percorrendo a fábrica. |
| **Recolhimento** | **Tirar do mercado** um produto que já foi vendido, porque tem problema. | |

## Documentos, pessoas e provas

| Palavra | O que é | Exemplo |
|---|---|---|
| **POP** | **Procedimento Operacional Padrão**: o passo a passo escrito de uma tarefa. | "Como limpar a máquina de encher frascos." |
| **Documento vigente** | A **versão oficial em uso hoje**. Versões antigas são "obsoletas" e não podem ser usadas. | |
| **Obsoleto** | Documento **antigo, substituído**, que não vale mais. | |
| **Treinamento** | Ensinar a pessoa a fazer a tarefa **e registrar** que ela aprendeu. | |
| **Função (do profissional)** | O "papel" da pessoa: o que ela **está autorizada a fazer** (amostrador, analista, aprovador). | |
| **Segregação de funções** | **Quem faz não pode ser quem confere.** Evita fraude e erro. | Quem conta o estoque não é quem aprova o ajuste. |
| **Assinatura eletrônica** | Provar **quem fez** uma ação no sistema, com senha, data e hora. | |
| **Trilha de auditoria** | O **histórico** que mostra quem mudou o quê, quando e por quê, e que **ninguém pode apagar**. | |
| **Pessoa Delegada** | A pessoa que **assina que o lote pode sair** para venda. É a última palavra antes de liberar. | Pela norma, sem ela, nenhum lote é vendido. |
| **Responsável pela Produção / pelo CQ** | O **chefe** de cada uma dessas áreas, nomeado pela empresa. | |
| **Registro (do produto)** | A **licença da ANVISA** para o remédio existir e ser vendido. Tem número e **validade**. | |
| **Estabilidade** | Acompanhar o remédio **ao longo do tempo** para provar que continua bom até a validade. | |
| **Água purificada e para injetáveis** | Água de **alto padrão de pureza**, usada para fabricar. É analisada o tempo todo. | |

## Palavras do sistema (que aparecem nas fichas)

| Palavra | O que é |
|---|---|
| **Ficha de fluxo** | Um documento do estudo que descreve **um processo da fábrica**, do começo ao fim, e como o sistema deve apoiá-lo. |
| **Legado** | O sistema **antigo** (LabMedSys) que estamos estudando para fazer o novo (iLabs). |
| **Falha do legado** | Algo que o sistema antigo **fazia errado**. Não vira requisito: vira requisito **corrigido**. |
| **"O banco garante"** | A regra é **conferida pelo banco de dados**, e não só pela tela. Mesmo que alguém tente burlar a tela, o sistema recusa. |
| **Nível 1, 2 e 3 (da GQ)** | Os três "graus de poder" do legado. 1: registra o que é seu. 2: responde por uma área. 3: abre, libera e aprova. |
| **Perfil** | O "pacote de telas e ações" que o sistema libera para uma pessoa. |
| **DV-GQ-016, CT-EST-050** | **Códigos de registro**. **DV** = defeito encontrado; **CT** = caso de teste. As letras seguintes dizem o módulo (GQ, EST, CQ, DOC, PRI). |
| **"Manda", "não define", "fora do alcance"** | No documento "O que a norma diz": *manda* = a norma obriga; *não define* = a norma exige o resultado mas a empresa decide como; *fora do alcance* = depende de um documento que ainda não temos. |
